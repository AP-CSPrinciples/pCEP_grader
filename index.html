Style checks by pycodestyle, the official PEP 8 checker, running in the browser with Pyodide. Naming checks follow the pep8-naming conventions. Programs run in a separate browser worker; time.sleep() and os.system() are skipped so pauses and screen clears don't cause timeouts.
